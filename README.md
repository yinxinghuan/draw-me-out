# DRAW ME OUT

An original bilingual visual role-playing game for AlterU.

You wake inside an unfinished image and discover that every generated world has different rules, different memories, and a different idea of who you are. Cross the latent layer, recover reality coordinates, protect—or abandon—the people who learned to see your choices, and decide who deserves to leave the frame.

## Development

```bash
npm ci
npm run dev
npm run build
```

The project uses React, TypeScript, Less, and Vite. Runtime narrative images use the AlterU media service. The repository contains no service credentials.

Game concept, story, interface, and generated key art are original to this project.
