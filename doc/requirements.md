# 《请把我画出去》需求文档

## 1. Overview

《请把我画出去》是一款以生成画面为主、短文字为辅的开放式角色扮演游戏：一个毫无技术背景的普通人意外掉进“画外之地”，穿入一幅幅规则不同的图片世界，寻找四条回家线索、结识画中角色，并决定自己是否应该独自离开。

目标玩家不需要理解人工智能术语。故事只使用“图片、草稿、撤销、加载、删掉、改图”等日常概念解释世界。首轮完整主线预计 45–75 分钟；单次图片世界为 3–5 次决策，适合 5–10 分钟分段游玩和续档。

### 游戏画像与承诺层级

- 单次形态：混合型。主要形态是一个 5–10 分钟的图片世界章节；次要形态是连续完成 45–75 分钟主线。
- 跨次连续性：持续叙事。三项状态、回家线索、撤销次数与永久代价、人物关系、已访问世界、章节和结局准备状态全部保存。
- 自然停止点：取得一条线索并回到画外之地后显示“阶段小结 · 已保存”；玩家可立即继续，也可从同一状态回来。
- 回访理由：剩余三条线索、画外之地发生的变化、小残对玩家的认识、抹平者的真相和最终出口选择。
- 发现承诺：进入失控图片，找齐四条回家线索，并决定是否独自离开。
- 首个有效动作承诺：入口上的“碰一下停在半空的雨”本身就是一次真实行动；它立刻冻结整条街、消耗余力并留下事实，进入后不得要求玩家重复点击同一动作。
- 首局承诺：玩家亲手发现雨城异常、遇见小残、帮助一个具体的人、取得一条线索，并理解第一次撤销为何有永久代价。
- 前 10 分钟承诺：玩家理解“观察规则—选择方法—承担差异后果—带回线索”的循环，并能说明至少两项状态为什么改变。
- 单次结束承诺：章节存档明确指出已经改变的世界、带回的线索、付出的代价和下一次可继续的目标。
- 长期承诺：四种线索必须能沿一条真实运行、可保存恢复的主干取得，并稳定解锁与既有事实兼容的结局；不能只在文档或测试夹具中直接补齐物品。

### 界面与体验合同

- 主要玩家：使用手机进入 AlterU 的普通玩家，也兼容桌面浏览器分享访问。
- 核心交互：观察当前画面与一句关键叙述，在 2–3 个行动中选择，或输入一个自由行动。
- 情绪承诺：先荒诞好笑，再逐渐让玩家关心同伴和“什么才算真正的我”。
- 第一焦点：当前生成画面；第二焦点：此刻需要理解的一句话；第三焦点：下一步行动。
- 目标画幅：手机竖屏为主；首次入口使用独立 16:9 建立镜头，核心剧情舞台使用 4:5；验证 320×568、390×844、430×932 以及 1366×768 桌面。
- 输入：选项使用一次点击立即提交；自由行动输入后点击发送；所有触控目标不小于 44×44 CSS px。
- 阅读门禁：结果正文有多页时，主按钮在最后一页前不得进入选择态；分页按钮只向前推进，不循环回第一页。最后一页读完后主按钮才从“继续阅读”切换为“查看下一步选择”。
- 选择前提：每组选项出现时，同屏必须保留一句不超过 82 个中文计量单位的“当前局面”，其中明确包含选项正在作用的地点、人物或物体；不能要求玩家凭记忆补回上一结果页。

### 普通玩家叙事合同

- 主角不是工程师，也不知道“潜空间、采样、权重、优化器”等概念；主角的技术知识不得高于普通玩家。
- 内部世界观遵守正确技术底座：所谓潜在空间并不是物理地点或空白画布，而是程序可读、人类感官无法直接理解的高维信息。游戏中的空白与碎片，是主角大脑对这些信息翻译失败后留下的主观感受，不是对真实数据结构的技术示意图。
- 世界真相必须先变成能看见、摸到或害怕的事情：雨停在半空、路人重复走路、出口会擦掉一个朋友。玩家先经历，再由角色给它取一个日常名字。
- 内部状态与协议可以保留技术 ID，但玩家只看到“我还是我、余力、被发现、回家线索、画外之地、抹平者”等通俗表达。
- 每个新名词第一次出现时，必须在同一屏用一个具体例子解释；一屏最多引入一个新概念。
- 行动选项只写“现在做什么”，采用一个动词加一个眼前对象或目的；中文优先不超过 18 字，禁止把世界观解释、抽象判断或专业术语塞进按钮。

## 2. Visual Design

游戏采用“稳定的取景框 + 不稳定的图片世界”。固定界面像一台正在审查生成结果的机器：深墨色细框、骨白信息纸、信号红游标线和低饱和蓝色行动色。每个图片世界可以改变绘画媒介、年代、光线和构图；“画外之地”不是一个可供站立的场景，而是主角对不可读信息的临时错译：大部分内容被感受成与骨白 UI 明确区分的深黑无边处，没有地面、方向、比例和远近关系，偶尔漏出颜色、边缘、材质、动作或光线的局部特征，却无法组成完整物体。主角以约 30–36% 画面高度的失重全身形象出现：不是大特写，也不会缩成符号；头像中的完整轮廓、形态、遮挡物、服装、颜色、花纹与配件都应可辨，周围仍保留占主体的黑暗空旷感。

核心页面为混合式固定舞台：上方是三项安静的状态栏；中间 4:5 画面尽量铺满屏幕；只有新增局面、人物台词或必要后果才以字幕浮在画面下部，纯“请做出选择 / 接下来怎么做”不占一层；行动结果与决策信息相互替换而非同时堆叠。选择仅在需要决策时出现，并可横向滚动。世界、行囊、状态、设置使用统一抽屉面板。

每一个成功推进的剧情步骤都安排一张 512×640 图片。玩家是主动作执行者时使用原始头像作为唯一参考，保留完整可见形象，而非只保留脸；环境、物品、NPC 主导画面不附带玩家头像参考。重大章节节点可在后续启用 5 秒竖屏视频，但静态画面始终作为回退。

首页入口、首个剧情画面与正式海报是三种用途不同的素材：首页使用 1024×576 的无人物宽幅建立镜头，悬停雨滴与黄色出口必须位于中央安全区；首个剧情画面由运行时按 512×640 生成并在玩家主导动作时引用头像；正式平台海报为 1024×1024，标题只允许英文 `DRAW ME OUT`，禁止中文、伪中文和其他可读文字。

## 3. Game Mechanics

### 开场五幕

1. 入口按钮就是玩家第一次伸手碰雨。雨滴呈玻璃质感，整条街同时停住；该动作立即消耗 4 点余力、确认“雨不是水”，并解释余力代表强迫画面改变所消耗的能力。
2. 玩家在已经看到换脸路人、街边白边和远处门后，从三种真实方法中选择一种调查。询问路人、触碰白边和直接冲门分别留下不同事实与数值代价，但都把玩家带到唯一没有重复的门。
3. 玩家在门边取得唯一一枚撤销键并坠入画外之地；这一步同时揭示“我还是我”，不再额外增加一次没有新决策价值的坠落确认。
4. 玩家掉进一片没有地面、天空与远近的深黑无边处，只知道这里在所有图片之外；目标先被说成一句人话：“找齐四样现实会回应你的东西，拼出回家的门。”
5. 玩家先看见红线里钻出一只非人的、像没折完白纸鸟的小生物；它亲口解释自己是“没被删干净的东西”，因为名字太长而自称“小残”，再明确成为向导。只有完成这段可见出场后，人物面板和选项才能使用“小残”这个名字。随后三组画面分别通往三个一眼可懂的麻烦。

小残出现后的第一组世界选择必须先说明规则：“画外之地会漏出无法自己结束的图片；帮助里面一个具体的人，会留下回家线索。”三个按钮只表示可辨认的入口——漂浮城市的蓝色裂缝、停在半句的王国裂缝、七年会议的荧光裂缝——不能在入口尚未介绍时直接命令玩家救送货员、帮助国王或结束会议。

前五幕每幕只有 1–3 句短文字和一个具体动作；世界观通过主角第一人称感受、环境异常与小残的反应逐步建立，不使用上帝视角说明书。开场采用输入驱动而非被动回顾：入口动作结算完成前不出现下一组选项或自由输入；进入场景后只显示其结果，玩家确认结果后才出现第一组真实选择。

所有固定和动态角色都遵守首次登场合同：先展示可辨认的外形或动作，再说明日常称呼的来源与当前关系，最后才开放对话、同行或相关行动。尚未登场的角色不进入人物面板，也不能提前出现在目标和按钮中。

### 核心循环

`画外之地休整 → 查看三扇门 → 选择一扇门或描述想去的世界 → 经历 3–5 个有后果的场景 → 帮助一个具体的人解决眼前麻烦 → 在原世界取得回家线索 → 主动穿回画外之地 → 看见线索落位与入口变化 → 才能选择下一扇门`

### 四线索战役导演（2026-08-13 改造合同）

四条必要线索不再由模型自行宣布。游戏保存一个明确的战役状态，并由本地剧情导演决定当前篇章、篇章阶段、已完成篇章、检查点和最终出口门槛；AI 只能表演已经被确认的局面。

- 四个必要篇章分别为：会飞走的城市（重量）、说话会成真的王国（空位）、永远散不了会的办公室（离开）、会给人贴标签的博物馆（被记住）。
- 每篇依次经过 `进入 → 看见具体问题 → 选择处理方法 → 承担可见结果 → 在原世界取得唯一线索 → 主动返回画外之地 → 在中转站确认线索落位`，共 4–6 次有效决定。每个阶段最多持续 2 回合，不能连续两回合只有气氛、确认或重复调查。
- “取得线索”和“返回画外之地”是两个独立权威回合。线索揭示镜仍处在刚解决的世界；下一回合必须由玩家选择如何穿回，并生成一张明确的无边处返回镜。返回镜完成、结果读完之前，下一世界入口不得出现在按钮或自由输入建议中。
- 画外之地是四个世界共享的固定中转站，不是一次性黑色背景：同一镜位始终保留中央红线环与四个固定锚位。每带回一条线索，对应锚位从空轮廓变成该线索的材质与颜色；刚离开的入口收拢成一处残痕，尚未进入的裂缝随后才重新亮起。
- 第一条线索之后，无边处固定显示剩余篇章的可辨认入口；玩家自由选择顺序。已完成入口保留变化痕迹，但不能重复发放线索。
- 每次行动先由剧情导演判断阶段和合法意图，再由领域规则原子结算地图、目标、数值、事实、物品、危险和章节检查点。AI 不得直接写入战役阶段。
- 自由输入若能明确对应当前三种方法之一，按该方法结算；无法对应时可形成 1 回合支线或可见受阻，但必须给出回到当前具体问题的路径，不能把篇章静默换成另一幅画。
- 其他图片世界继续作为可选探索内容，可产生关系、物品和跨世界事实；除非后来正式登记为必要篇章，不得代替四条主线线索。

### 画叙一致性合同

每回合完成规则结算后生成一份权威场景快照，至少包含当前地点、篇章阶段、可见人物、主动作、关键道具、光线/天气、与上一镜相比的变化以及禁止出现的对象。正文和图片都从同一快照派生，不能各自发明现场。

- 只有进入新世界、问题第一次显形、玩家行动造成可见改变、危险高潮/解决、线索揭示和返回无边处时刷新图片；其中线索揭示镜和返回镜必须是两个不同地点、两个不同回合。普通对话、补充观察和无视觉变化的状态说明沿用同一镜头。
- 图片表现一个确定时刻，优先选择动作结果或情绪峰值，不把同一回合的多个节拍拼成蒙太奇。
- 新图生成期间旧图仅作为上一镜参考，并在界面上降暗标记；生成失败时允许继续故事，但不得把旧图伪装成当前新地点。
- 图片提示词由场景快照与固定视觉圣经组装。模型提供的图片建议只能作为非权威构图参考，不能改变地点、人物、动作、道具和结果。
- 同一角色跨镜保持可辨认外形；尚未可见登场的角色禁止出镜；线索揭示图必须对应当回合真正进入行囊的稳定线索 ID。
- 稳定开场视觉锚点必须存在，但不要求它是运行时生成图：首页固定雨城建立镜头在第一张正确剧情图完成前作为同地点回退。雨城调查仍属于雨城；取得撤销键时先显示雨城瓦解的过渡镜；只有穿过门后才允许使用纯黑画外之地规则。
- 通用美术方向只能描述媒介、构图和质量，不得包含任何单一地点的环境合同。雨城、过渡、画外之地和四个图片世界分别从当前场景快照取得地点规则。
- 玩家主导画面没有有效头像引用时不得生成临时人类或替代角色；继续保留上一幕/同地点环境镜，直到调试头像、当前玩家头像或已记录的发布者回退头像可用。

- 同时活跃的剧情线最多 2 条。
- 每个支线最多 1–2 次选择，必须产生物品、关系、线索、危险或明确关闭结果。
- 连续 2–4 个安全回合后必须出现一次危险、代价或紧迫变化；危险结束后冷却 2 回合。
- 物理战斗少见。主要解决方式为识破世界规则、谈判、改写画面、交换记忆或利用物品。
- 每回合首句先写上一步的直接后果，最多再写 2 个短节拍；禁止“调查—确认—继续调查”的空循环。

### 三项状态

- 我还是我：0–100，初始 82。低于 35 显示警告，低于 12 进入身份崩解危险。单回合变化不超过 20。
- 余力：0–100，初始 65。低于 25 显示警告，低于 5 无法强行改变眼前世界。单回合变化不超过 24。
- 被发现：0–100，初始 18。高于 65 显示警告，高于 90 触发抹平者追捕。单回合变化不超过 20。

三项状态采用因果式逐项出现，而不是开场一次性展示抽象术语：第一次强迫画面改变后显示“余力”；画中人或抹平者开始回望玩家后显示“被发现”；画面试图替换玩家外形或身份后显示“我还是我”。每项首次出现必须由同回合正文和数值变化共同解释。旧存档进入已推进章节时直接显示全部已学会状态。

“回家线索”是行囊中的持久物品与主线进度，不作为第四项常驻数值。玩家需要至少 4 种现实会回应的证据，才可尝试开启出口：重量证明身体存在，空位证明选择没被替做，离开证明场景可以结束，被人记得证明身份不只是一张脸。

### 撤销键

撤销键初始 3 次。每次只针对一个已经登记的待发生后果，代价必须在使用前说清，并从仍然存在的记忆、关系或已确认事实中永久删去一项。界面只显示当前真实可支付且未支付过的代价；没有合法后果或代价时隐藏撤销行动。它不能用于无代价刷取更优随机结果，也不能重复收取同一段记忆。

### 领域规则裁判

首发可玩链路中的关键持久机制由本地规则一次性裁判，AI 只负责叙述可见后果和给出下一步行动：

- 撤销键是 1 件物品，不是 3 个按键；以 `0–3` 的已用次数为唯一真源，界面显示的剩余次数由 `3 - 已用次数` 派生。旧存档中数量为 3 的按键恢复为 1 件物品，不清空故事进度。
- 取得撤销键只发生一次；重复拿取、跳回原门或模型重复发放都不能增加物品或重置次数。
- 进入画外之地后，小残必须先按“外形—名字来源—同行关系”完整出现，才能以稳定身份加入；重复呼喊不会重复入队。
- 三个首发世界使用稳定地点 ID。第一次承诺世界后，不能在同一段旅程中通过另一句输入静默换线。
- 完成首个世界只能获得对应的 1 条回家线索；重复解决、模型额外发放或切换语言都不能复制线索与奖励。
- “线索奖励不重复”与“解决方法有差异”必须同时成立。直接介入、让小残冒险、利用当地规则等方法可获得同一条唯一线索，但必须分别写入稳定方法事实，并至少在余力、我还是我、被发现或跨世界事实中产生一项不同后果；领域层不得再把三个按钮压成完全相同的事务。
- `回家线索数量`、`第一条线索已取得`和`四条线索齐全`均从行囊中四个稳定线索 ID 派生，不能由叙述单独宣布。
- 直接选择“按下撤销键”但没有先说明永久代价时，动作必须被拒绝且零结算；说明“忘掉悬停雨滴的真相”等实际代价后，才消耗 1 次、删除对应事实并解决当前危险。相同代价不能重复删除。
- 任一受管辖动作命中后，该回合的数值、事实、物品、小队、地图、目标、时间、危险与章节暂停组成一个本地原子事务；模型夹带的其他持久化命令全部忽略。
- 非受管辖的对话、观察、自定义图片世界与自由行动继续交给 AI，不把开放叙事改成固定指令菜单。

验收路径至少覆盖：入口点击直接结算碰雨且不重复；雨城三种调查产生三个不同方法事实；同一图片世界三种解法获得相同唯一线索但产生不同代价；无代价撤销被拒绝 → 选择明确代价后成功 → 同一代价不可重复；进入一个首发世界 → 精确获得其一条线索 → 重复领取被拒绝；恶意模型命令不能修改任何额外状态。

### 第四堵墙递进

- 第一层：图片人物把按钮、字幕和加载状态误认为天气、神谕或建筑。
- 第二层：小残和少数觉醒角色能看见玩家的选项、重试痕迹与生成失败，并据此行动。
- 第三层：后期角色会质疑正在屏幕外做选择的人是否才是真正的“玩家”，结局可直接利用续档、重开和玩家输入，但不得读取或伪造设备隐私。

### 首发图片世界

1. 会飞走的城市：没钱的人每天只有十五分钟能踩到地面，一名送货员正抱着早餐飞向天空。
2. 说话会成真的王国：天空总抢着把话说完，一个错误名字就会让无辜的人进监狱。
3. 永远散不了会的办公室：一句“再补充一点”让会议开了七年，只有保洁员记得外面还有生活。
4. 会给人贴标签的博物馆：这里的展品反过来给游客下定义，标签写错，人也会跟着改变。
5. 儿童画海岸：太阳有十二条腿，海水从纸边漏走；这里的居民害怕被大人“画正确”。
6. 被丢掉的画：所有画坏、画错、没被采用的东西在这里活了下来，藏着最接近现实的线索。

AI 可以继续生成新世界，但必须使用同一核心循环、状态合同、持久事实和节奏上限。

## 4. Controls

- 点击行动选项：同一帧出现按下反馈，150–220 ms 内锁定该选项并立即提交；网络与生图不阻塞文字结果。
- 横向滑动：只滚动当前 2–3 个行动选项；卡片内部使用点击而非按下触发，避免误选。
- 自由行动：点击输入区后输入内容，点击统一 SVG 发送图标提交；空文本不可提交。
- 点击画面：仅在画面有分页提示时翻阅当前叙述页，不承担隐藏的关键操作。
- 点击状态、世界或行囊：打开抽屉，查看详细状态、持久事实、关系、回家线索和物品；再次点击或向下关闭。
- 声音、文字大小、重新开始：位于设置面板。重新开始需要二次确认；有存档再次进入时弹出“继续游戏 / 重新开始”，继续后直接定位到当前场景。
- 键盘：桌面端数字键 1–3 选择行动，Enter 提交自由行动，Escape 关闭抽屉。

## 5. Win / Lose Conditions

游戏没有简单的“生命归零即删档”。“我还是我”降至 0、“余力”降至 0 或“被发现”达到 100 时，玩家会被强制弹回画外之地，并承受可恢复但持久的后果；若存在撤销键，可在确认代价后使用。玩家始终可以继续、从章节锚点恢复或主动重新开始。

主线在玩家取得至少 4 条回家线索，并对“谁应该离开”作出决定后进入结局导演。结局由大语言模型根据持久状态生成，至少结合以下 8 个结局能力：

1. 回到一个看似现实、但仍可能是生成图的清晨。
2. 让自己离开，但永远失去小残对自己的记忆。
3. 放弃出口，留在画外之地为后来被困者带路。
4. 带一名生成角色进入现实，并承担身份交换的后果。
5. 阻止抹平者，把所有入口永久打开。
6. 删除出口，保住会因玩家离开而消失的图片世界。
7. 接受自己可以有多种形象，不再把单一外观视作真实证明。
8. 与小残一起面对屏幕外的一次选择，把最终回答交给玩家自由输入。

AI 不得仅复述上述标题；它要根据玩家保存/放弃的世界、伙伴关系、撤销代价、四墙认知和最后行动生成具体尾声。结局页包含：结局名、2–4 个短段落、关键人物去向、保留/失去的事实、重新开始和带着结局继续探索两个选项。

## 6. Sound Effects

- 画外之地环境：78 BPM 的稀疏低频脉冲、倒放铅笔摩擦和远处数字噪声；音量 0.18，不使用持续高频。
- 普通选择：100–160 ms 的干燥按键声，440–620 Hz 短音，音量 0.22。
- 世界入口：450 ms 上升的颗粒滑音，180→760 Hz，音量 0.28。
- 世界返回：550 ms 倒放纸张与低频落点，音量 0.30。
- 状态增益：两音上行 520/690 Hz，总时长 220 ms，音量 0.20。
- 状态损失：两音下行 260/170 Hz，总时长 260 ms，音量 0.23。
- 被发现警告：每 2.4 秒最多一次 90 ms 短脉冲，不叠加，音量 0.24。
- 危险/规则断裂：280 ms 的纸张撕裂与低频冲击，音量 0.35。
- 回家线索：600 ms 的清澈三音 520/780/1040 Hz，音量 0.30。
- 撤销键：700 ms 倒放打字机和瞬时静音 80 ms，音量 0.34。
- 结局：根据实际结局从画外主题派生 8–12 秒的短尾声；不自动播放人声。

音频必须在用户第一次交互后才启动；失败为非致命。静音和 `prefers-reduced-motion` 模式下，所有关键信息仍由文字与状态变化表达。
