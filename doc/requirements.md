# 《请把我画出去》需求文档

## 1. Overview

《请把我画出去》是一款以生成画面为主、短文字为辅的开放式角色扮演游戏：一个毫无技术背景的普通人意外掉进“画外之地”，穿入一幅幅规则不同的图片世界，寻找四条回家线索、结识画中角色，并决定自己是否应该独自离开。

目标玩家不需要理解人工智能术语。故事只使用“图片、草稿、撤销、加载、删掉、改图”等日常概念解释世界。首轮完整主线预计 45–75 分钟；单次图片世界为 3–5 次决策，适合 5–10 分钟分段游玩和续档。

### 界面与体验合同

- 主要玩家：使用手机进入 AlterU 的普通玩家，也兼容桌面浏览器分享访问。
- 核心交互：观察当前画面与一句关键叙述，在 2–3 个行动中选择，或输入一个自由行动。
- 情绪承诺：先荒诞好笑，再逐渐让玩家关心同伴和“什么才算真正的我”。
- 第一焦点：当前生成画面；第二焦点：此刻需要理解的一句话；第三焦点：下一步行动。
- 目标画幅：手机竖屏为主；首次入口使用独立 16:9 建立镜头，核心剧情舞台使用 4:5；验证 320×568、390×844、430×932 以及 1366×768 桌面。
- 输入：选项使用一次点击立即提交；自由行动输入后点击发送；所有触控目标不小于 44×44 CSS px。

### 普通玩家叙事合同

- 主角不是工程师，也不知道“潜空间、采样、权重、优化器”等概念；主角的技术知识不得高于普通玩家。
- 内部世界观遵守正确技术底座：所谓潜在空间并不是物理地点或空白画布，而是程序可读、人类感官无法直接理解的高维信息。游戏中的空白与碎片，是主角大脑对这些信息翻译失败后留下的主观感受，不是对真实数据结构的技术示意图。
- 世界真相必须先变成能看见、摸到或害怕的事情：雨停在半空、路人重复走路、出口会擦掉一个朋友。玩家先经历，再由角色给它取一个日常名字。
- 内部状态与协议可以保留技术 ID，但玩家只看到“我还是我、余力、被发现、回家线索、画外之地、抹平者”等通俗表达。
- 每个新名词第一次出现时，必须在同一屏用一个具体例子解释；一屏最多引入一个新概念。
- 行动选项只写“现在做什么”，采用一个动词加一个眼前对象或目的；中文优先不超过 18 字，禁止把世界观解释、抽象判断或专业术语塞进按钮。

## 2. Visual Design

游戏采用“稳定的取景框 + 不稳定的图片世界”。固定界面像一台正在审查生成结果的机器：深墨色细框、骨白信息纸、信号红游标线和低饱和蓝色行动色。每个图片世界可以改变绘画媒介、年代、光线和构图；“画外之地”不是一个可供站立的场景，而是主角对不可读信息的临时错译：大部分内容被感受成与骨白 UI 明确区分的深黑无边处，没有地面、方向、比例和远近关系，偶尔漏出颜色、边缘、材质、动作或光线的局部特征，却无法组成完整物体。主角以约 30–36% 画面高度的失重全身形象出现：不是大特写，也不会缩成符号；头像中的完整轮廓、形态、遮挡物、服装、颜色、花纹与配件都应可辨，周围仍保留占主体的黑暗空旷感。

核心页面为混合式固定舞台：上方是三项安静的状态栏；中间 4:5 画面尽量铺满屏幕；当前一句叙述、人物台词和行动结果以相互替换而非同时堆叠的方式浮在画面下部；选择仅在需要决策时出现，并可横向滚动。世界、行囊、状态、设置使用统一抽屉面板。

每一个成功推进的剧情步骤都安排一张 512×640 图片。玩家是主动作执行者时使用原始头像作为唯一参考，保留完整可见形象，而非只保留脸；环境、物品、NPC 主导画面不附带玩家头像参考。重大章节节点可在后续启用 5 秒竖屏视频，但静态画面始终作为回退。

首页入口、首个剧情画面与正式海报是三种用途不同的素材：首页使用 1024×576 的无人物宽幅建立镜头，悬停雨滴与黄色出口必须位于中央安全区；首个剧情画面由运行时按 512×640 生成并在玩家主导动作时引用头像；正式平台海报为 1024×1024，标题只允许英文 `DRAW ME OUT`，禁止中文、伪中文和其他可读文字。

## 3. Game Mechanics

### 开场五幕

1. 玩家在一张仍在生成的雨夜城市图中醒来；周围人的脸在眨眼间重复，玩家先通过身体和环境感受异常。
2. 一个路人说到一半换了三张脸，远处门外不是房间，而是一片还没涂完的颜色。
3. 玩家穿过门，世界边缘像湿纸一样卷起；第一次获得“撤销键”，同时发现它已有使用痕迹。
4. 玩家掉进一片没有地面、天空与远近的深黑无边处，只知道这里在所有图片之外；目标先被说成一句人话：“找齐四样现实会回应你的东西，拼出回家的门。”
5. 玩家遇到“小残”——一只像折纸鸟和鼠标游标混合而成的小生物。它只知道自己是“没被删干净的东西”，并不知道系统原理。随后三扇门分别通往三个一眼可懂的麻烦。

前五幕每幕只有 1–3 句短文字和一个具体动作；世界观通过主角第一人称感受、环境异常与小残的反应逐步建立，不使用上帝视角说明书。

### 核心循环

`画外之地休整 → 查看三扇门 → 选择一扇门或描述想去的世界 → 经历 3–5 个有后果的场景 → 帮助一个具体的人解决眼前麻烦 → 获得回家线索/物品/同伴 → 世界坍缩或主动离开 → 返回已经发生变化的画外之地`

- 同时活跃的剧情线最多 2 条。
- 每个支线最多 1–2 次选择，必须产生物品、关系、线索、危险或明确关闭结果。
- 连续 2–4 个安全回合后必须出现一次危险、代价或紧迫变化；危险结束后冷却 2 回合。
- 物理战斗少见。主要解决方式为识破世界规则、谈判、改写画面、交换记忆或利用物品。
- 每回合首句先写上一步的直接后果，最多再写 2 个短节拍；禁止“调查—确认—继续调查”的空循环。

### 三项状态

- 我还是我：0–100，初始 82。低于 35 显示警告，低于 12 进入身份崩解危险。单回合变化不超过 20。
- 余力：0–100，初始 65。低于 25 显示警告，低于 5 无法强行改变眼前世界。单回合变化不超过 24。
- 被发现：0–100，初始 18。高于 65 显示警告，高于 90 触发抹平者追捕。单回合变化不超过 20。

“回家线索”是行囊中的持久物品与主线进度，不作为第四项常驻数值。玩家需要至少 4 种现实会回应的证据，才可尝试开启出口：重量证明身体存在，空位证明选择没被替做，离开证明场景可以结束，被人记得证明身份不只是一张脸。

### 撤销键

撤销键初始 3 次。每次可以逆转一个重要坏结果、救回被删角色或重开坍缩路线；代价必须在使用前说清，并从记忆、关系或已确认事实中永久删去一项。它不能用于无代价刷取更优随机结果。

### 第四堵墙递进

- 第一层：图片人物把按钮、字幕和加载状态误认为天气、神谕或建筑。
- 第二层：小残和少数觉醒角色能看见玩家的选项、重试痕迹与生成失败，并据此行动。
- 第三层：后期角色会质疑正在屏幕外做选择的人是否才是真正的“玩家”，结局可直接利用续档、重开和玩家输入，但不得读取或伪造设备隐私。

### 首发图片世界

1. 会飞走的城市：没钱的人每天只有十五分钟能踩到地面，一名送货员正抱着早餐飞向天空。
2. 说话会成真的王国：天空总抢着把话说完，一个错误名字就会让无辜的人进监狱。
3. 永远散不了会的办公室：一句“再补充一点”让会议开了七年，只有保洁员记得外面还有生活。
4. 会给人贴标签的博物馆：这里的展品反过来给游客下定义，标签写错，人也会跟着改变。
5. 儿童画海岸：太阳有十二条腿，海水从纸边漏走；这里的居民害怕被大人“画正确”。
6. 被丢掉的画：所有画坏、画错、没被采用的东西在这里活了下来，藏着最接近现实的线索。

AI 可以继续生成新世界，但必须使用同一核心循环、状态合同、持久事实和节奏上限。

## 4. Controls

- 点击行动选项：同一帧出现按下反馈，150–220 ms 内锁定该选项并立即提交；网络与生图不阻塞文字结果。
- 横向滑动：只滚动当前 2–3 个行动选项；卡片内部使用点击而非按下触发，避免误选。
- 自由行动：点击输入区后输入内容，点击统一 SVG 发送图标提交；空文本不可提交。
- 点击画面：仅在画面有分页提示时翻阅当前叙述页，不承担隐藏的关键操作。
- 点击状态、世界或行囊：打开抽屉，查看详细状态、持久事实、关系、回家线索和物品；再次点击或向下关闭。
- 声音、文字大小、重新开始：位于设置面板。重新开始需要二次确认；有存档再次进入时弹出“继续游戏 / 重新开始”，继续后直接定位到当前场景。
- 键盘：桌面端数字键 1–3 选择行动，Enter 提交自由行动，Escape 关闭抽屉。

## 5. Win / Lose Conditions

游戏没有简单的“生命归零即删档”。“我还是我”降至 0、“余力”降至 0 或“被发现”达到 100 时，玩家会被强制弹回画外之地，并承受可恢复但持久的后果；若存在撤销键，可在确认代价后使用。玩家始终可以继续、从章节锚点恢复或主动重新开始。

主线在玩家取得至少 4 条回家线索，并对“谁应该离开”作出决定后进入结局导演。结局由大语言模型根据持久状态生成，至少结合以下 8 个结局能力：

1. 回到一个看似现实、但仍可能是生成图的清晨。
2. 让自己离开，但永远失去小残对自己的记忆。
3. 放弃出口，留在画外之地为后来被困者带路。
4. 带一名生成角色进入现实，并承担身份交换的后果。
5. 阻止抹平者，把所有入口永久打开。
6. 删除出口，保住会因玩家离开而消失的图片世界。
7. 接受自己可以有多种形象，不再把单一外观视作真实证明。
8. 与小残一起面对屏幕外的一次选择，把最终回答交给玩家自由输入。

AI 不得仅复述上述标题；它要根据玩家保存/放弃的世界、伙伴关系、撤销代价、四墙认知和最后行动生成具体尾声。结局页包含：结局名、2–4 个短段落、关键人物去向、保留/失去的事实、重新开始和带着结局继续探索两个选项。

## 6. Sound Effects

- 画外之地环境：78 BPM 的稀疏低频脉冲、倒放铅笔摩擦和远处数字噪声；音量 0.18，不使用持续高频。
- 普通选择：100–160 ms 的干燥按键声，440–620 Hz 短音，音量 0.22。
- 世界入口：450 ms 上升的颗粒滑音，180→760 Hz，音量 0.28。
- 世界返回：550 ms 倒放纸张与低频落点，音量 0.30。
- 状态增益：两音上行 520/690 Hz，总时长 220 ms，音量 0.20。
- 状态损失：两音下行 260/170 Hz，总时长 260 ms，音量 0.23。
- 被发现警告：每 2.4 秒最多一次 90 ms 短脉冲，不叠加，音量 0.24。
- 危险/规则断裂：280 ms 的纸张撕裂与低频冲击，音量 0.35。
- 回家线索：600 ms 的清澈三音 520/780/1040 Hz，音量 0.30。
- 撤销键：700 ms 倒放打字机和瞬时静音 80 ms，音量 0.34。
- 结局：根据实际结局从画外主题派生 8–12 秒的短尾声；不自动播放人声。

音频必须在用户第一次交互后才启动；失败为非致命。静音和 `prefers-reduced-motion` 模式下，所有关键信息仍由文字与状态变化表达。
