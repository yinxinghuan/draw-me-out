# 《请把我画出去》领域规则层实验

> 日期：2026-08-12  
> 范围：开场至第一条回家线索、第一次撤销  
> 结论：通过；改造保留开放叙事，同时消除了本段最容易漂移的数值与唯一性状态。

## 实验问题

原实现把剧情协议交给模型生成，语义很灵活，但同一回合可能同时出现互相冲突的物品、事实、地图和数值命令。最明显的例子是“撤销键”在文案上是一枚有三次机会的物件，协议却把它保存成 `count=3`；第一次撤销也没有要求一个可验证、不可重复的永久代价。三条首世界路线和三条首线索依赖翻译后的地点名与模型同时写 item/fact，存在重复领取、跨路线跳转和里程碑漂移风险。

## 改造边界

本地领域裁判只接管有精确经济或连续性后果的动作：唯一道具、首次登场、路线锁、一次性线索、危险恢复和章节 checkpoint。普通观察、交谈、探索与自定义世界仍保持 AI 自由生成。

当前 12 条规则覆盖：

- 撤销键获取（普通取得与跳入颜色两个代价分支）；
- 进入无边处；
- 小残按“可见外形—名字来源—关系—入队”顺序登场；
- 飞城、语言王国、七年会议三条稳定首路线；
- 重量、空位、离开三条首线索只结算一次；
- 免费撤销拒绝；
- 明确永久忘掉“悬停的雨”后完成第一次撤销。

## 自动对抗结果

`npm run test:domain` 在每个受管回合注入恶意模型命令：把数值设到极端、添加 99 个假线索、跳到虚构地图、让未登场的默认七号入队、重写目标和时间、提前结束章节并给出错误选项。最终本地状态仍为：

- 撤销键数量 1，初始剩余 3，支付一次后剩余 2；
- 小残只在可见登场回合创建并成为唯一同行者；
- 第一世界路线固定为 `flying-city`；
- 重量线索数量 1，重复领取为零效果；
- `home-clue-count=1`、`first-coordinate-earned=true`、`coordinates-four=false` 均由行囊重建；
- 免费撤销不扣次数、不平息危险、不结束章节；明确代价后才原子完成。

## 浏览器实玩结果

在 390×844、Cinematic Civic、demo 模式中从开局实际玩到第一次撤销，路径为：雨城 → 唯一撤销键 → 无边处 → 小残登场 → 飞城 → 重量线索 → 重复领取被拒 → 抹平者 → 免费撤销被拒 → 忘掉悬停的雨并撤销。

浏览器直接读取隔离后的真实存档，验证物品数、线索派生事实、撤销次数、永久代价事实和章节结束状态；同时验证 result 与 decision 不会同时显示。证据在 `_qa/ui/domain-platform-layout-*.png`，完整脚本为 `_qa/playthrough.mjs`。

## 对通用模式的新结论

1. 领域事务不只包括数值、物品和地图；如果一个关键事件同时改变目标、时间或章节 checkpoint，它们也必须在同一次本地事务中提交。
2. 受管回合的下一组选项也是状态结果。模型选项若与已提交状态不一致，会把玩家重新导向非法分支，因此模型的所有协议命令（包括 choices）都应丢弃，由 rule resolution 安装合法选项。
3. “已找到几条 / 是否已集齐”这类事实若只是稳定物品所有权的视图，应从行囊派生，不能让模型同时写 item 与 fact。
4. 固定但未登场的角色可由 party effect 创建，但只允许在同回合可见成功正文已经完成合法首次登场时发生。

这些结论已同步进 `build-stateful-story-game` 的两套冻结模板与 `references/domain-rules.md`，后续游戏可直接声明 Cartridge 规则而无需重写裁判器。
